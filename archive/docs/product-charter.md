# Midwest24 Archive — Product Charter

Midwest24 Archive is institutional memory infrastructure for MIDWESTGuard and the first production application within the Midwest24 ecosystem.

Archive is not a file browser, cloud drive, or simple document manager. It exists to preserve, organize, relate, secure, search, retrieve, and improve organizational knowledge.

## Mission

Engineer institutional memory that survives people, technology, and time.

## MVP Goal

The MVP is complete when MIDWESTGuard can:

- authenticate users
- upload files
- create archive records
- store structured metadata
- organize records by type, category, tag, and relationship
- search records
- retrieve files
- audit meaningful actions
- backup and restore the system

## Product Boundary

Archive owns:

- backend
- frontend
- API
- database
- metadata
- file storage
- search
- authentication
- authorization
- indexing
- deployment
- documentation
- testing

Archive does not own ERP, CRM, accounting, estimating, fleet, scheduling, marketing, or investor strategy.
