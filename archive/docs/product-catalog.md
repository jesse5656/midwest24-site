## Naming Rule

Use official Midwest24 product names in documentation, diagrams, workflows, manuals, and user-facing materials.

Use implementation technology names only when discussing installation, configuration, troubleshooting, APIs, security, licensing, migrations, or infrastructure.

Example:

Midwest24 Core Drive is implemented using Nextcloud.

Not:

Nextcloud is the product.

## Guiding Principle

Products define the platform.

Technologies implement the platform.

The Midwest24 product identity should remain stable even if implementation technologies change.
