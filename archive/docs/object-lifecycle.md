# Midwest24 Archive Object Lifecycle

Version: 0.1.0

Status:
Foundational Draft

------------------------------------------------------------------------------

## Purpose

This document defines the lifecycle of every Knowledge Object within Midwest24 Archive.

All object types should follow a consistent lifecycle unless explicitly overridden.

------------------------------------------------------------------------------

## Guiding Principle

Knowledge should mature.

Objects should evolve through defined states rather than existing as static records.

------------------------------------------------------------------------------

## Standard Lifecycle

Draft

↓

Active

↓

Reviewed

↓

Validated

↓

Referenced

↓

Archived

------------------------------------------------------------------------------

## Draft

The object has been created but has not yet been reviewed.

Characteristics:

- editable
- incomplete
- low confidence

------------------------------------------------------------------------------

## Active

The object is actively being developed or used.

Characteristics:

- visible
- searchable
- linkable

------------------------------------------------------------------------------

## Reviewed

The object has received human review.

Characteristics:

- verified
- corrected
- approved for operational use

------------------------------------------------------------------------------

## Validated

The object has demonstrated value through implementation or evidence.

Characteristics:

- trusted
- reusable
- recommended

------------------------------------------------------------------------------

## Referenced

The object is actively cited by other knowledge objects.

Characteristics:

- contributes to organizational knowledge
- supports decisions
- supports research

------------------------------------------------------------------------------

## Archived

The object is retained for historical purposes.

Characteristics:

- read-only
- searchable
- preserved

------------------------------------------------------------------------------

## Lifecycle Rules

Objects should never be deleted without policy.

Knowledge should be preserved whenever practical.

Historical decisions retain value.

------------------------------------------------------------------------------

## Guiding Principle

Knowledge compounds through stewardship.
