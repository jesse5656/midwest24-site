# Midwest24 Archive — Project Charter

Version: 0.1.0
Status: Active Product Definition

## Mission

Midwest24 Archive is the first product module of Midwest24 Core.

Its purpose is to preserve, organize, search, and retrieve business knowledge, documents, SOPs, records, media, and institutional memory for MIDWESTGuard LLC first, then future contractor clients.

## Product Goal

Build a secure archive system with both backend and frontend functionality.

The system should eventually support:

- document storage
- file metadata
- tagging
- search
- AI-assisted retrieval
- permissions
- audit history
- client/project/job relationships
- SOP and knowledge capture
- backup and export
- future integration with MIDWESTGuard operations

## Initial Customer

MIDWESTGuard LLC.

## Product Philosophy

This is not just file storage.

This is institutional memory infrastructure.

The objective is to reduce dependence on individual memory and make company knowledge searchable, transferable, and durable.

## MVP Scope

The first version should include:

- user authentication strategy
- document upload
- document listing
- metadata fields
- basic search
- category/tag structure
- project/customer/job association
- secure access control
- frontend dashboard
- backend API
- database schema
- deployment documentation

## Out of Scope for MVP

- full ERP
- full CRM
- accounting
- scheduling
- complex AI agents
- external client billing
- public SaaS onboarding
- enterprise HA infrastructure

## Success Criteria

The MVP succeeds when MIDWESTGuard can store, find, and retrieve important operational documents faster than current workflows.
