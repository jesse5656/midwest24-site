# Midwest24 Core Records icon — generation record

## Purpose

Create the dedicated launcher icon for **Midwest24 Core Records**, the internal
financial-records and evidence workspace implemented with Paperless-ngx.

## Visual authority

- Approved family: `../reference/midwest24-core-launcher-family-approved-2026-10-29.png`
- Complete review: `../reference/midwest24-core-launcher-family-records-review-20261105.png`
- Versioned export: `../releases/records-20261105/midwest24-core-records.png`

## Design and review

The selected source was generated on November 5, 2026 and resized without
cropping to a 240 × 240 PNG. It uses the approved dimensional navy shield,
royal-blue/navy field, upper-left cyan light, white inset, and a distinct white
two-drawer records cabinet with a file tab. The pictogram is intentionally
different from the existing Documents page and Files folder marks.

The Records export was reviewed in the complete launcher sheet, including the
existing approved family plus Workspace and Files. It is readable at launcher
size and has a distinct evidence/records meaning.

## Release boundary

This file records the approved production asset. An Authentik launcher mapping
and the `records.midwest24.com` route are separate release actions and must not
be represented as live until they are verified.
